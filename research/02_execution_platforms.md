# Sniper bot & execution platform landscape for Solana memecoins — platform-by-platform teardown and the self-hosted sub-second stack

## Executive summary

The single most important finding: BullX/BullX Neo suspended all trading functionality on 1 June 2026 and has not resumed; wallets/withdrawals remain open but the community treats it as a permanent shutdown. Do not architect around it. Second: essentially NONE of the retail "sniper platforms" (Photon, Axiom, Trojan, Bloom, Nova, Vector, Padre/Terminal, Pepeboost, BonkBot, Banana Gun, Maestro) expose a public programmatic trading API — they are UI or Telegram surfaces, and Photon explicitly states it is built for manual trading with third-party automation scripts to be treated as unsafe. The one real exception is GMGN.ai, which publishes a genuine REST trading API (get_swap_route → sign locally → send_transaction), but it is gated behind a volume-based application and rate-limited to one call per five seconds, which disqualifies it as a sniper execution path (it is usable as a fallback/exit router only). Therefore, for a bot that must fire in <1s of a signal, the platform layer is a dead end and the answer is a fully self-hosted stack. Fee-wise the platforms cluster tightly at 1.0% gross with referral/cashback pulling effective rates to roughly 0.75–0.90% (Axiom's published cashback ladder runs Wood 0.95% → Champion 0.75%, with a 10% referral discount; volume thresholds are unpublished), so there is no meaningful fee arbitrage between them — self-hosting saves the entire ~1% platform take, which is the largest single controllable line item. On trust: Axiom suffered a ZachXBT-documented February 2026 insider scandal in which employees used an over-permissive internal admin dashboard to inspect prominent traders' "private-only" wallet activity — for a systematic bot this is strategy-leakage risk, not just reputational. Banana Gun was drained ~$3M across 11 wallets in September 2024 via a Telegram message-oracle bug (fully reimbursed, then hardened with 2FA and a 2-hour transfer delay); Maestro is outright custodial with a single one-time mnemonic export. The recommended best-in-class stack is: Yellowstone gRPC/Geyser (or ShredStream) for detection, locally-constructed pump.fun/PumpSwap/Raydium instructions with no RPC round-trip in the hot path, and submission via Helius Sender Max (0.001 SOL min tip, multi-path to Helius+Jito+Harmonic+Rakurai) and/or direct Jito sendBundle. All-in cost for a self-hosted 1 SOL pump.fun bonding-curve snipe is roughly 1.25% venue fee + ~0.0012 SOL fixed (tip + priority + base) ≈ 1.37% one-way before slippage, versus ~2.37% one-way through a 1% platform. Because tip and priority fees are fixed in SOL and not proportional, there is a hard minimum viable trade size around 0.5 SOL below which fixed costs exceed 0.25% of notional. Critically, Alpenglow's 150ms finality is NOT live — it is targeted for Agave 4.3 / October 2026 mainnet activation, and at least one vendor blog wrongly describes it as already shipped; build against the current 400ms slot. Finally, the base-rate math is brutal and should dominate position sizing: a peer-reviewed survival analysis of 832,941 launches (May–June 2026) puts the pump.fun graduation rate at 0.198%, with presence of a Telegram link lifting it 8.94x and initial market cap above the 30 SOL default being the strongest single predictor (Cox HR 4.51).

## Numeric parameters

- **jito_min_tip_lamports** = `1000` — Official Jito docs minimum tip (0.000001 SOL). A secondary source claimed no minimum exists — trust the docs. Absolute floor for any bundle.
- **helius_sender_max_min_tip_sol** = `0.001` — Hard requirement for Sender Max multi-path routing. Note this is ~200x the observed median landed tip (5e-6 SOL) and ~1.4x the 99th percentile — a real cost, so gate it behind a contested-ness check.
- **helius_sender_swqos_only_min_tip_sol** = `0.000005` — SWQOS-only tier minimum via ?swqos_only=true. 200x cheaper than Sender Max. Use for non-contested exits and scale-outs.
- **tip_percentile_normal** = `75` — Practitioner guidance for a normal launch; corresponds to 7.128e-6 SOL at the 2026-08-23 observed tip floor. Read live from the tip_floor API, do not hardcode the SOL value.
- **tip_percentile_contested** = `95` — Practitioner guidance when the block is contested; 9.2676e-5 SOL at the observed floor. One vendor engine uses the 80th percentile of the last 50 successful inclusions in the same opportunity category.
- **tip_cap_fraction_of_expected_profit** = `0.50 to 0.70` — Observed stabilized ceiling for what competitive searchers pay to win inclusion. Enforce as a hard cap so a mis-scored signal cannot tip away the entire edge.
- **solana_base_fee_lamports_per_signature** = `5000` — Fixed protocol base fee. Negligible alone but include it in the fixed-cost floor.
- **compute_unit_limit_swap** = `200000` — Typical CU consumption for a complex swap; network max is 1,400,000 per transaction. Set explicitly rather than relying on the 200k-per-instruction default so priority fee math is deterministic.
- **slot_time_ms** = `400` — Current Solana slot time as of August 2026. Alpenglow's ~150ms finality is NOT live — targeted Agave 4.3 / October 2026. Make this a config value, not a constant.
- **account_read_latency_ms** = `40 to 50` — Cost of a single account read even on a good endpoint, per the Chainstack reference bot. This is why the hot path must contain zero RPC round-trips — one read is ~5% of a 1s budget.
- **end_to_end_latency_budget_ms** = `under 150 target; under 30 achievable on dedicated infra` — Vendor-published targets (medium confidence, RPC Fast is selling infrastructure). Sub-30ms detect-to-send is claimed as sufficient to land in the same slot as the trigger event.
- **blockhash_validity_seconds** = `60` — GMGN docs state transactions expire after ~60 seconds (last_valid_height). Applies generally — pre-signed transaction templates must be refreshed within this window.
- **pumpfun_bonding_curve_fee_pct** = `1.25` — Total bonding-curve fee: 0.95% protocol + 0.30% creator. The commonly-cited 0.25% figure is stale and understates round-trip cost by ~200bp.
- **pumpswap_fee_pct_by_mcap_sol** = `0-420: 1.25 | 420-1470: 1.20 | 1470-2460: 1.15 | 2460-3440: 1.10 | 98000+: 0.30` — Implement as a lookup table, not a constant. The 95bp spread between smallest and largest tiers materially changes exit economics.
- **pumpfun_graduation_fee_sol** = `0.015` — Fixed fee when a coin graduates from the bonding curve to PumpSwap, inclusive of network fees.
- **raydium_cpmm_fee_tiers_pct** = `1, 2, 4` — Raydium CPMM tiers. CLMM tiers are 0.02, 0.03, 0.04, 2. Detect actual pool type before modeling — assuming legacy 0.25% AMM v4 on a CPMM pool is a 75–375bp per-side error.
- **jupiter_ultra_fee_bps** = `5 to 10` — 0.05–0.10%, dramatically cheaper than the ~100bp retail platforms, but Ultra's 700ms–2s /execute makes it unsuitable for entries.
- **platform_fee_pct_retail_baseline** = `1.0 gross, 0.75-0.90 effective` — Photon, BullX (defunct), Axiom, Trojan, BonkBot, Maestro, Bloom, Nova, Pepeboost all cluster at 1% gross. This is the per-side saving from self-hosting and the single largest controllable cost.
- **min_viable_trade_size_sol** = `0.5` — Fixed costs (0.001 SOL tip + ~0.0002 priority + 0.000005 base ≈ 0.0012 SOL) are size-independent. Below ~0.5 SOL notional they exceed 0.25% of the trade and swamp the edge; at 0.1 SOL they are ~1.2%.
- **all_in_cost_one_way_self_hosted_pct** = `~1.37 plus slippage` — On a 1 SOL pump.fun bonding-curve snipe: 1.25% venue + ~0.12% fixed (tip/priority/base). Round trip ~2.7-3% plus slippage both sides.
- **all_in_cost_one_way_via_platform_pct** = `~2.37 plus slippage` — Same trade plus a 1% platform fee. Round trip ~4.7%+. The platform layer roughly doubles all-in cost.
- **slippage_tolerance_pct** = `0.3-0.5 tight execution; 0.5-2 typical memecoin reality` — Sources disagree. 0.3–0.5% is a vendor recommendation for tight execution; practitioner cost breakdowns assume 0.5–2% actual on memecoin launches. Use a wide bound with a fixed token quantity for zero-RPC fast-mode buys.
- **pumpfun_graduation_rate_pct** = `0.198 (95% CI 0.189-0.208)` — Peer-reviewed, n=832,941 launches May 8–Jun 10 2026. Steady-state 0.207%. DEXTools independently reports ~0.26% mid-June 2026. Down 3.18x from 0.63% in Sept–Oct 2025.
- **filter_require_telegram_link** = `true` — Graduation 1.485% with a Telegram channel vs 0.166% without — 8.94x lift, Cox HR 5.40 (95% CI 4.73–6.17). Highest-value single filter and free to evaluate from metadata.
- **filter_require_all_three_socials** = `preferred` — 1.919% graduation with all three social channels vs 0.110% with none — a 17.4x lift.
- **filter_min_initial_mcap_sol** = `greater than 30` — Initial market cap above the 30 SOL platform default is the strongest single predictor, Cox HR 4.51; the top quartile graduates at 0.634%.
- **token_survival_past_90d_pct** = `4.55` — Of 18.67M tokens launched Jan 2024–Jun 2026; a CoinGecko study independently found ~5%. 68.67% recorded their last trade on the same day they launched — argues for hard time-based exits in minutes to hours.
- **rugcheck_rate_limit_per_min** = `10 unauthenticated / 60 authenticated` — 60/min is 1/sec — usable for async confirmation only, never inside a hot path that may see dozens of launches per second.
- **gmgn_rate_limit_seconds_per_call** = `5` — One call per 5 seconds per API key. Disqualifies GMGN as a sniper execution path.
- **jito_rate_limit_req_per_sec_per_ip_per_region** = `1` — The most commonly missed binding constraint. Mitigate by fanning out across the 8 mainnet regional endpoints, each of which has its own budget.
- **node_max_rps_default** = `25` — Chainstack reference bot's default token-bucket rate limit against the RPC node. Reasonable starting point; public RPCs are explicitly insufficient for this workload.

## Traps and failure modes

- BullX dependency is now a worked example of total platform risk: it suspended all trading on 1 June 2026 with no warning, no timeline and no airdrop after collecting a reported $200M+ in fees. Any architecture routing execution through a third-party frontend can be zeroed overnight. This is the strongest single argument for the self-hosted path.
- Almost every retail platform in this landscape (Photon, Axiom, Trojan, Bloom, Nova, Vector, Padre, Pepeboost, BonkBot, Banana Gun, Maestro) has NO public trading API. Driving them means Telegram userbot automation or browser scraping — both are ToS violations, both break on every UI change, and both add hundreds of milliseconds that make a <1s budget impossible. Photon explicitly warns that third-party automation scripts should be considered unsafe.
- GMGN is the tempting trap: it has a real API, so it looks like the answer, but one call per 5 seconds means you cannot even fetch a route fast enough for a single signal, let alone a stream of them. Do not discover this after building against it.
- Jupiter Ultra looks like the obvious managed solution and is genuinely well-built, but its own published numbers (/order 300ms P50, /execute 700ms–2s) exceed a 1s end-to-end budget before the transaction is even broadcast. Use Swap V2/Metis to build instructions and submit them yourself instead.
- Alpenglow's 150ms finality is NOT live — it targets Agave 4.3 / October 2026. At least one vendor blog states it as already shipped and claims bots tuned for 400ms slots are 'now systematically late'. Building against phantom network parameters will mis-tune every timing constant you have.
- Hijacked GitHub repos are actively distributing malware in this exact niche. The single highest-starred 'Solana sniper' repo (4,438 stars) has a created_at of 2013 — years before Solana existed. Two other high-star repos date to 2013 and 2014. Old repos are recycled precisely because star count and repo age are the trust heuristics developers use. Never run one with a funded .env.
- Any account read between signal detection and submission costs ~40–50ms even on a good endpoint — roughly 5% of a 1s budget. Reading the bonding curve to compute an exact price before buying is the most common self-inflicted latency leak. Buy a fixed token quantity from streamed CreateEvent data with a wide slippage bound instead.
- Jito's 1 request/second per IP per region limit silently throttles bursty strategies. During a launch wave you will exceed it instantly and get 429s. Fan out across all 8 mainnet regional endpoints and/or request a raised limit before you need it.
- Helius Sender rejects any transaction missing EITHER the SOL tip transfer OR the setComputeUnitPrice instruction. This is an easy omission that manifests as a total submission failure under load rather than a clear error at build time.
- The 0.001 SOL minimum tip on Sender Max and Nozomi is ~200x the observed median landed tip (5e-6 SOL) and exceeds even the 99th percentile (7.02e-4 SOL). Paying it indiscriminately on every trade — including uncontested exits — is a large and completely avoidable cost. Gate the tier by contested-ness.
- Tip and priority fees are fixed in SOL and do not scale with position size, so they silently destroy small trades: ~0.0012 SOL of fixed cost is 1.2% of a 0.1 SOL trade but 0.024% of a 5 SOL trade. Enforce a minimum viable trade size (~0.5 SOL) or the fee floor eats the strategy.
- Modeling pump.fun at the widely-repeated 0.25% is a 100bp-per-side error — the bonding curve is 1.25% and PumpSwap starts at 1.25% for sub-420-SOL market caps. Similarly, assuming Raydium's legacy 0.25% AMM v4 on what is actually a 1%/2%/4% CPMM launchpad pool understates cost by 75–375bp per side. A backtest built on stale fee constants will show profit where none exists.
- Axiom's February 2026 insider scandal is a strategy-leakage risk, not a custody risk: employees used an over-permissive admin dashboard to inspect prominent traders' private wallet activity. For a systematic bot, an operator observing your entry pattern can copy or front-run it, degrading alpha silently and invisibly. Non-custodial does not mean unobserved.
- Maestro is genuinely custodial — keys are generated and held on their infrastructure — and permits only a SINGLE mnemonic export. Banana Gun and Photon also allow only one-time key export. Miss that one export and the wallet is permanently platform-locked.
- Banana Gun's September 2024 exploit drained ~$3M from 11 wallets and specifically targeted 'smart money' via manual transfers rather than an automated drain. Being a profitable, identifiable bot operator raises rather than lowers your targeting risk on any custodial or semi-custodial surface.
- Jupiter's legacy portal rate-limit grandfathering expired 30 June 2026. If billing was never set up on the new Developer Platform, rate limits can collapse without an obvious error — a realistic silent outage mode.
- 'Sub-millisecond execution' (Bloom v2.0) is physically impossible for on-chain settlement on a 400ms-slot chain. Treat all vendor speed claims in this category as marketing, and every RPC-vendor benchmark as sales material — RPC Fast's '10% of bots profit / 90% fail on latency' figures come from a company selling latency.
- The base rates are the real risk, not the infrastructure: a 0.198% graduation rate means even a well-filtered candidate has under a 2% chance of graduating, and 68.67% of tokens die the same day they launch. A stack that fires in 200ms into unfiltered launches simply loses money faster. Position sizing and hard time-based exits matter more than shaving another 20ms.
- Sources conflict on effective fees for several platforms (Padre/Terminal: 0.8% vs 35% cashback; MEVx: 0.8% vs 0.9–1%; Trojan: 0.5% vs 0.55% vs 0.75%). Axiom's cashback tier volume thresholds are entirely unpublished — one source explicitly warns that any guide quoting a dollar threshold is guessing. Do not encode these as facts.
- No substantive fee, custody or API data could be located for Vector in this research. Treat it as unverified rather than assuming it matches the 1% cohort.
- Specific holder-concentration thresholds (e.g. 'reject if top-10 non-LP holders exceed X%') could not be verified from any credible source — the 12-point safety checklists circulating come from paid press releases (openpr.com) and vendor marketing. Calibrate your own cutoff against the CC-BY-4.0 Zenodo dataset of 860,213 labeled launches rather than adopting a quoted number.

## Findings

### BullX / BullX Neo suspended all trading functionality on 1 June 2026 and has not resumed operations

Trading functionality was suspended starting June 1, 2026, announced via Discord and framed as a pause for 'future upgrades' with no timeline or roadmap published since. Wallet functionality including withdrawals and management remains operational; user assets are not locked. Community consensus treats it as permanent closure. Major grievance: the platform collected a reported >$200M in fees from a userbase that farmed points for an airdrop that never materialized. Prior to shutdown BullX charged 1% and covered ~9 chains. No exploit or breach is associated with the shutdown; trades were executed on-chain with BullX acting as an execution layer rather than a custodian, with private keys reportedly downloadable within 48 hours of wallet creation (that 48h claim is low-confidence secondary sourcing).

**Actionable:** Remove BullX/BullX Neo from all integration plans and from any comparison logic. If any legacy code or config references neo.bullx.io, delete it. Treat this as the canonical worked example of platform-dependency risk: any architecture whose execution path routes through a single third-party frontend can be zeroed overnight with no warning, which is the core argument for the self-hosted path.

`confidence=high` · source: https://crypto.news/bullx-pauses-meme-trading-tool-but-keeps-wallet-access-open/

### Axiom is non-custodial via Turnkey, charges 1% gross with a published cashback ladder to 0.75%, but suffered a documented insider-surveillance scandal in February 2026

Fees: 1% gross on spot. Referral signup gives a 10% discount on trading fees (≈0.9% effective from day one); how referral stacks with cashback is undocumented. Cashback ladder (7 tiers, net fee): Wood 0.95%, Bronze 0.90%, Silver 0.875%, Gold 0.85%, Platinum 0.825%, Diamond 0.80%, Champion 0.75%. Volume thresholds per tier are NOT published by Axiom — the source explicitly warns 'Any guide quoting a specific dollar threshold per tier is guessing.' Referral revenue share: 30% direct, 3% second level, 2% third. Perps route to Hyperliquid at 0.01% per transaction plus Hyperliquid's own maker/taker schedule. Default priority fee and Jito tip are both 0.001 SOL, and neither prevents sandwich attacks. Custody: non-custodial, keys managed via Turnkey air-gapped infrastructure; email/Google signup auto-provisions a Turnkey-backed wallet. SECURITY: On 26 February 2026 ZachXBT published an investigation alleging multiple Axiom employees abused internal admin tooling to look up private wallet information and track 'private-only' wallet activity of prominent traders and influencers, beginning early 2025; one employee was named (Broox Bauer). Axiom issued a formal apology, suspended the employees involved, admitted internal access controls were 'unnecessarily permissive', and promised an internal audit. Axiom is a Y Combinator W25 company.

**Actionable:** Do not route bot flow through Axiom. The insider incident is not a fund-loss risk (non-custodial) but is a strategy-leakage risk: an operator with dashboard access could observe your wallet's entry patterns and front-run or copy them, which directly degrades alpha for a systematic strategy. If you use Axiom at all, use it only as a manual research UI with a wallet that never touches bot capital, and never label wallets in-app. Also note the 0.001 SOL default Jito tip as a useful reference point — it matches Helius Sender Max's minimum and is a sane hardcoded default for your own tip floor.

`confidence=high` · source: https://financefeeds.com/zachxbt-exposes-axiom-insider-trading-scandal-involving-internal-tool-abuse/

### GMGN.ai is the only major platform in this set exposing a genuine public trading API, but its 1-call-per-5-seconds rate limit disqualifies it for sniping

Three endpoints. (1) Route: GET https://gmgn.ai/defi/router/v1/sol/tx/get_swap_route with params token_in_address, token_out_address, in_amount (lamports), from_address, slippage. Returns quote plus an unsigned base64 transaction. Anti-MEV via Jito supported with is_anti_mev=true and a minimum 0.002 SOL fee. (2) Submit: POST https://gmgn.ai/txproxy/v1/send_transaction — you base64-decode the returned tx, deserialize as VersionedTransaction, sign with your local key, re-encode base64, post. (3) Status: GET https://gmgn.ai/defi/router/v1/sol/tx/get_transaction_status with hash and last_valid_height; transactions expire after ~60 seconds. Auth: apply via Google Form, approval granted solely on sufficient GMGN trading volume, reviewed within 24h, API key emailed and passed in the x-route-key header. RATE LIMIT: 'Each API Key is rate-limited to one call every 5 seconds.' Custody is effectively non-custodial for API use since you sign locally. Platform fee ~1% (0.9–1% with referral discounts). GMGN also ships an Agent API / MCP skill架 at github.com/GMGNAI/gmgn-skills covering Solana, BSC and Base. Reputation: widely regarded as best-in-class for copy trading and wallet analytics, but reported to lag during extreme volume spikes.
